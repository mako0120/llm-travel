# 情報品質と不確実性表示

旅行情報は `high`、`medium`、`low`、`unknown` の確信度で扱う。`low` と `unknown` は「情報未確定」「未確認」と明示し、料金・時刻・空室を確定事実として表示しない。費用の構成要素に `low` または `unknown` が一つでもある場合、合計は「概算費用」と表示する。

フォールバックは決定的に選ぶ。必須要件が未確認なら `stop`、宿泊・予算に影響する項目が未確認なら `ask_user`、同じ枠に代替候補がある未確認候補なら `exclude_candidate`、それ以外は `continue_with_labels` で不確実性を示して続行する。候補を除外した場合は理由を結果に残す。

このポリシーは実在する旅行情報の真実性を保証しない。時刻表には公式または経路提供者の検証済み情報、飲食の評価・口コミ数には指定された根拠、宿泊の価格と空室には新鮮な証拠が必要である。
