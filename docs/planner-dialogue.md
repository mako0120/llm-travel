# 旅行プランナー対話

`travel.planner` は、最初に `AI旅行計画を作成しますか？` だけを返します。`はい` の後、住まい・行き先・宿泊数・テーマ・王道/穴場・予算・宿泊タイプ・交通・特別要望を順番に質問します。回答収集中は次の質問だけを返し、条件がそろうと `planning_brief` を作成します。

このbriefは後続の旅行生成Providerへ渡すデータです。Google、TikTok、食べログの名称は検索命令ではなく、取得結果に出典・取得時刻・検証状態を添えるための要件です。現時点で外部サイトを取得する実装はありません。

モデルルートの表示形式は次です。

```text
時間：...｜スケジュール：...｜場所：...｜費用：...｜備考：王道 / 穴場｜移動ルート：路線名・駅名・所要時間
合計費用：...円（移動費：...円、宿泊費：...円、食費：...円、入場料：...円）
```

`render_model_route` は取得・検証済みの値を表示するだけです。不明な項目は `未確認` と表示し、価格、評価、口コミ数、時刻表、移動時間、空室を創作しません。
