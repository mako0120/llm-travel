# 体験価値と改善ルールの方針

この試作では、旅行の体験価値を高めるため、景観・場所の魅力・食事を候補比較で明示的に重視する。運転負担と安全への不安、入浴・お土産時間、事前説明、雨天代替案も計画時の確認項目にする。

利用者から共有された7段階評価は、景観 6.71、場所の魅力 6.57、食事 6.07、移動 6.14、日程 6.00、宿泊 5.57、総合 6.57 だった。場所の魅力と総合評価の相関は 0.795、食事は 0.619 だった。この観察値は因果関係や他の旅行への一般化を示すものではなく、計画の優先順位を説明するための監視コンテキストとして扱う。

改善提案と再利用ルールの根拠は、自由記述コメントだけに限定する。保存する根拠は `qualitative_comment_only` と、実在するコメント付きフィードバックIDである。点数、平均、相関、閾値、ランキングを単独で改善ルールの作成・承認・優先順位付けに使わない。コメントには個人情報を入力しない。
